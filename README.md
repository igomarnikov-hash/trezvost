# Шаг за шагом — PWA для трезвости

Счётчик трезвости с юбилеями, дневник и поиск групп АА рядом. Все данные хранятся только на устройстве (localStorage).

## Как развернуть
PWA работает только по HTTPS (или localhost). Любой статический хостинг подойдёт:

**VPS (nginx):**
```
scp -r trezvost/* user@server:/var/www/trezvost/
```
```nginx
server {
  server_name sober.example.ru;
  root /var/www/trezvost;
  location / { try_files $uri $uri/ /index.html; }
  location = /sw.js { add_header Cache-Control "no-cache"; }
  types { application/manifest+json webmanifest; }
}
```
затем `certbot --nginx -d sober.example.ru`.

**Бесплатно:** перетащите папку на app.netlify.com/drop или залейте в GitHub Pages.

## Установка на телефон
- Android/Chrome: кнопка «Установить приложение» в разделе «Ещё» или меню браузера → «Установить».
- iPhone/Safari: «Поделиться» → «На экран Домой».

## Обновление
Поменяйте `VERSION` в `sw.js` — у пользователей подтянется новая версия.

## Группы АА
`groups-data.js` — 251 группа Москвы и МО с сайта aamos.ru (адрес, метро, телефон, расписание, координаты), выгрузка 11.11.2026.
Чтобы обновить: пересоберите файл в том же формате (одна строка — одна группа, поля через `|`) и поднимите `VERSION` в `sw.js`.

## Ежедневник
Текст книги «Ежедневные размышления» не входит в приложение (авторские права АА). Пользователь загружает свой экземпляр:
- **TXT**: каждая дата — отдельной строкой «11 НОЯБРЯ», затем заголовок, цитата, строка-источник (`..., с. 84`), текст.
- **JSON**: `{"11-11": {"title": "...", "quote": "...", "source": "...", "text": "..."}}` или массив объектов с полем `date`.
